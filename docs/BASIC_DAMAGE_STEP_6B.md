# Damage Calculator — Step 6B

Implements only Hidden Power, Return, Frustration, Low Kick, Flail and Reversal. `variableDamage.js` resolves canonical move type/power; `basicDamage.js` then uses the unchanged ordinary modifier, stage, STAB, ordered type-chart and random-roll pipeline. The popup uses the same resolver for its existing type icon and Power field. No retired calculator imports, KO predictions, new controls or CSS changes.

## Verified cartridge rules

Primary sources: [battle script commands](https://github.com/pret/pokeemerald/blob/master/src/battle_script_commands.c), [HP scaling](https://github.com/pret/pokeemerald/blob/master/src/battle_interface.c), [base damage](https://github.com/pret/pokeemerald/blob/master/src/pokemon.c), [Tower generation](https://github.com/pret/pokeemerald/blob/master/src/battle_tower.c), [Frontier Brain generation](https://github.com/pret/pokeemerald/blob/master/src/frontier_util.c).

- Hidden Power reuses `hiddenPower.js`: IV order HP, Attack, Defense, Speed, Special Attack, Special Defense. Least-significant bits form type index `floor(bits*15/63)` across Fighting through Dark; next bits give `floor(bits*40/63)+30`. The resolved type determines Gen 3 category, STAB, chart and existing item/ability/weather modifiers. All-zero IVs give Fighting30; all31 give Dark70.
- Return: `floor(10*friendship/25)`; Frustration: `floor(10*(255-friendship)/25)`. Zero dynamic power falls back to reference power1 in `CalculateBaseDamage`; effective minimum1, maximum102. Exact imported friendship is retained. Missing player friendship alone defaults to255 for Return and0 for Frustration; malformed values are rejected.
- Ordinary generated Tower opponents and Anabel Brain Pokémon start at friendship255, changed to0 when any set move is Frustration. The existing `frontierAdapter.js` already supplies that verified value; no adapter change was necessary. Missing Frontier friendship is rejected rather than using player defaults. Factory-specific generation, recorded parties, e-Reader and apprentices are outside the supported Tower Singles data model.
- Low Kick uses existing species weights for the defender: below10/25/50/100/200kg gives20/40/60/80/100, otherwise120. Adapter weight can supply a reliable fallback for a battler without a known species entry; unavailable/nonpositive/nonfinite data omits damage.
- Flail and Reversal use `max(1,floor(48*currentHP/maxHP))` for a living attacker. Inclusive fraction limits1/4/9/16/32/48 give200/150/100/80/40/20 power. Explicit Conditions HP takes precedence, then imported initial/current/max HP. Invalid or fainted HP omits damage. Normal and Fighting remain distinct types. No HP is changed.

## Independent numerical fixtures

Literal expected values are calculated from the cartridge formula, not generated by the production calculator:

- Level50, Attack100, Defense100, Normal defender, Fighting Hidden Power30: base15, weakness30, random25–30 HP.
- Same attacker Special Attack200, Dark Hidden Power70: base63, random53–63 HP. Dark STAB against Psychic:94 after STAB,188 after weakness,159–188 HP.
- Normal Return102, Attack/Defense100: base46, STAB69,58–69 HP. Friendship70 gives Return28 and Frustration74. Minimum-power Return produces3–4 HP with Normal STAB.
- Low Kick120, Attack/Defense100 versus Normal: base54, weakness108,91–108 HP.
- HP1/200, Attack/Defense100: Flail200 with Normal STAB114–135 HP; Reversal200 against Normal153–180 HP.
- Ice Hidden Power70, Special Attack200: Ice STAB79–94 HP normally; Thick Fat40–48 HP, preserving separate ability outcomes.
- HP-bracket tests use maxHP480 and values on both sides of every threshold; Low Kick tests include every exact weight boundary. All supported Tower and Anabel sets are checked for friendship, plus selected-trainer and Brain IV fixtures.
